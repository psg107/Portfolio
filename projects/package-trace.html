사내 문의 자동응답 에이전트란

사내 문의 자동응답 에이전트는 여행 패키지 사업부의 Slack 문의를 읽고 사내 서비스의 실제 데이터와 소스 코드를 조회해 근거와 추정을 구분한 답변을 게시하는 서버 시제품이다. 상품이 판매되지 않거나 예약이 취소된 이유를 묻는 문의는 개발자가 같은 조회를 직접 수행하므로 건당 30분에서 2시간이 소요된다.

판매 날짜가 표시되지 않는다는 문의가 재고 0의 정상 동작으로 밝혀진 경우처럼, 이런 문의의 답은 상품의 현재 값과 그 값을 판단하는 코드 조건을 대조해야 확인된다.

로컬 환경에서 동작을 확인한 단계이고 서버 배포와 실제 문의 기준의 품질 검증은 진행되지 않았다.

구성

총괄 에이전트가 역할별 에이전트를 도구처럼 호출하고, 결과는 사업부 메시지와 개발자 스레드로 나누어 게시된다.

문서 검색에서 문의 시점 조회로

에이전트는 문서를 미리 적재하지 않고 문의를 처리하는 시점에 도구로 데이터와 코드를 조회한다. 답을 확인하는 데 필요한 현재 값과 코드 조건은 문서가 담지 못하는 정보이기 때문이다.

첫 시도인 AI 챗봇 문서 학습 서비스는 품질 미달로 실제 문의에 투입되지 않았고 기록이 없어 그 원인은 추정 수준이다. 원인과 별개로 현재 값과 코드 조건은 적재 대상이 아니어서 검색을 개선해도 이 문의에는 답하지 못한다.

문의 시점 조회는 서버 구현 전에 Claude Code 스킬로 수동 실행해 방향을 확인한 방식이다. 문의 하나가 에이전트의 반복 호출로 이어져 LLM 호출 수는 문서 검색 방식보다 많고, 실제 문의 기준의 비용은 측정되지 않았다.

문의 수신

문의자는 게시 뒤 스레드 댓글로 추가 정보를 작성하는 경우가 많다. 그래서 서버는 5분마다 채널을 조회하되 게시 후 5분이 지난 메시지만 처리하고, 웹훅과 달리 지연 실행 처리가 필요 없으며 내부 서버의 주소도 노출하지 않는다.

에이전트 실행 뒤 작성된 댓글은 문맥에서 제외되고, 문의가 집중되면 대기가 길어진다.

증거 수집과 판정의 분리

잘못된 답변은 답변하지 않는 경우보다 결과가 나쁘므로 판정은 변형되지 않은 증거를 기준으로 수행되어야 한다. 에이전트 하나가 조회와 판정을 함께 수행하는 구조와 달리, 판정 에이전트에는 데이터 조회 도구가 없어 판정의 입력이 전달받은 증거와 파일 읽기 결과로 한정된다.

호출 순서는 프롬프트 지침에 속해 코드가 판정 에이전트의 호출을 보장하지 않는다. 에이전트를 한 번씩 지나는 구조는 데이터와 사용법 문의를 대상으로 하고, 오류가 로그에만 있는 장애 문의에는 확인됨 판정을 내리지 못한다.

소스 색인

탐색 에이전트는 클래스와 함수의 위치와 호출처를 MongoDB에 미리 저장한 소스 색인에서 조회한다. 색인에는 파일 원문도 저장되어 탐색 중 GitHub API 호출은 원문이 없는 파일로 한정된다.

색인 없이 탐색하는 방식제약
GitHub Code Search API분당 10회 제한이 탐색의 병목이 된다.
grep 순차 탐색탐색 자체에 토큰과 시간이 소모된다.
clone과 ctags배포 대상으로 계획한 컨테이너가 재시작되면 clone이 사라진다.

참조는 이름의 일치로 판단해 같은 이름의 다른 대상도 호출처로 기록된다. 탐색 에이전트에는 파일을 읽어 확인한 뒤 인용하도록 지시하므로 이 오차는 호출처 후보의 증가로 나타나고, 프론트엔드 코드의 제약은 색인 대상이 아니어서 탐색되지 않는다.

탐색 주의 사항 저장

같은 이름의 클래스가 여러 계층에 있으면 탐색 에이전트가 잘못된 코드를 먼저 탐색하기도 하고, 이때 에이전트가 그 혼동을 탐색 주의 사항으로 저장한다. 코드에서 확인할 수 있는 결론은 저장 대상이 아닌데, 저장된 결론이 실제 데이터와 충돌하면 에이전트가 저장된 결론에 치우치기 때문이다.

확인됨과 추정의 판정

주장마다 확인됨 또는 추정이 표시되고, 확인됨은 코드 조건과 실제 값을 추론 없이 대조할 수 있을 때만 허용된다.

정확도를 우선한 기준이라 호출 경로가 복잡한 문의에서 코드를 찾지 못하면 결론 전체가 추정이 된다. 판정 기준은 프롬프트 지침이고 인용의 실재를 검사하는 코드는 없어, 판정을 사람이 검증하는 수단은 개발자 스레드의 인용이다.

맡은 범위
