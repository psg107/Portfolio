규칙과 훅

규칙과 훅이란

이 환경에서 모든 세션이 지켜야 하는 작업 규칙은 전역 지침(~/.claude/CLAUDE.md)에 문장으로 정의되어 있다. 세션은 시작할 때 전역 지침을 읽고, 작업 중에는 에이전트가 스스로 판단해 규칙을 지킨다.

문장 규칙은 에이전트의 판단에 따라 지켜지므로 여러 세션이 같은 규칙을 반복해서 어길 수 있다. 예고만 하고 턴을 끝내지 않는다는 규칙이 전역 지침에 추가된 당일에도 한 세션이 다음 작업을 예고하고 턴을 끝내 약 9시간 동안 멈춰 있었다(예고 후 중단 판정).

그래서 반복해서 어겨지는 규칙은 훅이 실행 시점마다 검사한다. 훅의 검사는 에이전트의 판단과 관계없이 실행된다.

훅은 설정 파일(~/.claude/settings.json)에 실행 시점과 함께 등록되고, 전역 지침의 규칙 문장 옆에는 그 규칙을 검사하는 훅의 경로가 명시되어 있다.

실행 시점별 훅

아래 도해에서 행은 훅의 실행 시점이고, 열은 훅이 실행된 결과다.

  • 맥락 추가는 훅 출력을 에이전트의 다음 입력에 추가하는 일이다.
  • 가드는 규칙에 어긋난 호출을 거부하는 훅이다.
  • 'git 명령 가드'와 '파일 작성 가드'는 각각 가드 여러 개를 한 상자로 표시한 이름이다.
  • 훅 상자의 첫 줄은 ~/.claude/hooks/ 기준 경로다.

이 탭은 모든 세션에 적용되는 훅만 설명한다. 토픽 상태 문서를 갱신하게 하는 훅은 토픽 탭의 갱신 훅에서 설명하고, 등록된 훅 전체 목록은 전체 구조 탭의 구성 요소 목록에 있다.

가드 해제

가드는 규칙에 어긋난 호출을 모두 거부하므로, 사용자가 명시적으로 요청한 예외를 처리하려면 가드를 해제할 수 있어야 한다. 그래서 이 환경은 가드 해제 명령(guard-unlock)을 제공한다.

에이전트가 사용자 발화를 10자 이상 그대로 인용해 해제 명령을 실행하면 가드 하나가 해제된다. 해제는 해제 명령을 실행한 턴에서만 유효하다.

실행 시점훅하는 일
도구 실행 전lock/turn_unlock.py
  • 해제 명령의 인용이 10자보다 짧으면 해제 명령을 거부한다.
  • 인용이 10자 이상이면 해제 상태를 세션별 해제 파일에 기록한다.
턴 종료와 요청 제출lock/relock.py
  • 해제 파일을 삭제해 가드를 다시 잠근다.

예고 후 중단 판정

턴이 끝나면 에이전트는 사용자가 다시 요청할 때까지 작업하지 않으므로, 할 일을 예고만 하고 턴을 끝낸 세션은 그대로 멈춘다.

턴 종료 훅 finish/stop.py 는 마지막 응답을 아래 도해 순서로 검사한다. 응답이 예고로 끝났으면 훅이 턴 종료를 막고 사유를 에이전트에 전달하므로, 에이전트는 같은 턴에서 작업을 이어 간다.

판정에는 아래 예외를 둔다.

  • 인용 안의 예시 문구는 예고가 아니므로 판정에서 제외한다.
  • 백그라운드 작업이 끝나면 완료 알림이 세션의 다음 턴을 시작하므로, 응답이 그 작업을 기다린다는 문장으로 끝나면 훅은 종료를 허용한다.
  • 훅은 이미 한 번 막은 종료를 허용하므로, 종료 차단은 한 턴에 한 번만 일어난다.

설정 검사기

설정 폴더 ~/.claude 는 여러 세션이 함께 사용하므로, 세션마다 정해지지 않은 위치에 메모나 스크립트를 작성하기 쉽다. 설정 검사기(config/lint.py)는 설정 폴더에 정해진 파일만 정해진 위치에 있는지 검사한다.

설정 폴더를 대상으로 한 도구 실행이 끝나면 훅 config/notify.py 가 설정 검사기를 실행한다. 훅은 오류가 있을 때만 검사 결과를 맥락에 추가한다.

스킬 작성 검사기

설정 검사기는 스킬의 이름과 폴더 구조를 검사한다. 스킬 본문과 설명 형식은 스킬 작성 검사기(skills/skill/scripts/skill-lint.py)가 검사한다.

도구가 스킬 정의 문서를 수정하면 훅 skill/notify.py 가 하위 스킬을 포함한 스킬 폴더 전체에 스킬 작성 검사기를 실행한다. 스킬은 모델이 읽는 문서이므로 토큰이 적게 드는 영어로 작성한다.
