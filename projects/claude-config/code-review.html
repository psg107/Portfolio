코드 리뷰

코드 리뷰란

이 환경에서 에이전트는 코드 리뷰를 두 방향으로 수행한다.

  • 리뷰하는 쪽에서는 팀원 PR이나 사용자의 PR을 검토해 지적을 PR 댓글로 게시한다.
  • 리뷰받는 쪽에서는 사용자의 PR이 받은 지적이 맞는지 확인해 코드를 수정하거나 반박한다.

두 방향마다 스킬이 하나씩 있다.

  • 관점별 리뷰 스킬(pr:nitpick)은 PR의 변경을 정확성이나 성능 같은 관점마다 서브에이전트에게 배정해 검사하고, 지적을 기각하려면 반박 서브에이전트에게 그 지적을 옹호하게 한다.
  • 리뷰 지적 처리 스킬(pr:resolve)은 받은 지적마다 같은 관점과 판정 규칙으로 근거를 다시 확인해 수용 여부를 판정한다.

구성

pr:nitpick은 PR을 리뷰해 지적을 PR 댓글로 게시하고, pr:resolve는 PR이 받은 지적을 처리한다. 사용자의 PR을 셀프 리뷰할 때는 두 스킬을 번갈아 실행하는 라운드를 반복하고, 다음 라운드의 pr:nitpick은 앞 라운드 답글이 반박 근거로 적은 명령을 다시 실행해 반박이 맞는지 확인한다.

pr:nitpick의 로컬 전용 모드는 자율 구현 스킬이 PR을 생성하기 전에 로컬 변경을 리뷰할 때 사용하는 모드이고, 지적을 PR 댓글 대신 로컬 파일에 기록한다.

관점별 리뷰

에이전트 하나가 변경 전체를 한 번 읽고 리뷰하면 결함을 누락하거나, 찾은 결함을 문제가 아니라고 잘못 판정해 지적에서 제외(기각)한다. 실제로 자율 구현 스킬의 리뷰 에이전트가 기각한 지적 두 개를 다음 날 동료 리뷰어가 다시 지적했다.

그래서 pr:nitpick은 변경을 관점마다 서브에이전트에게 배정하고, 수집한 지적을 게시 전에 다시 검증한다. 지적을 기각하려면 반박 서브에이전트가 그 지적을 옹호해 보게 한다.

지적 등급은 높은 순서로 blocker와 major와 minor와 nit이다.

점선은 지적을 하나도 제기하지 않은 관점의 서브에이전트를 다시 실행하는 경로다.

지적 처리

받은 지적은 맞는지 확인한 뒤에 수용하거나 반박해야 한다. 그래서 pr:resolve는 지적마다 리뷰 대상 브랜치의 최신 커밋(head)에서 근거를 다시 실행하고 판정을 하나 선택한다.

pr:resolve는 관점 회고 결과로 개인 설정 저장소에 draft PR을 생성한다.

판정 규칙

관점별 서브에이전트가 제기한 지적과 받은 지적에는 틀린 지적이 포함된다. 그래서 두 스킬은 아래 규칙에 따라 지적을 유지하거나 삭제한다.

대상규칙
틀린 지적
  • 사실이나 인과가 틀린 지적은 등급과 관계없이 삭제한다.
사소한 지적
  • 사소하다는 이유로 삭제하지 않고 등급만 낮춘다.
지적의 기각
  • 코드를 보며 지적을 옹호한 반박 서브에이전트가 실패한 경우에만 기각한다.
부재와 개수 주장
  • 검색 결과를 근거로 한 지적은 메인 에이전트나 검증 에이전트가 검색을 다시 실행한다.
  • 남은 지적이 약 80건을 초과하면 검색 재실행을 검증 에이전트 2~3개에 분배한다.
작성자 반박
  • 답글이 확인할 수 있는 사실로 지적을 닫으면 그 확인 명령을 다시 실행한다.
  • 반박이 반증되면 지적을 복원한다.
  • 틀린 반박은 새 지적으로 게시한다.
받은 지적의 비수용
  • 반증한 명령과 출력이나 코드 위치를 답글에 기록한다.
  • 기록할 수 없으면 보류로 판정한다.
